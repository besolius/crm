# CRM Forever – prototip interactiv

Prototip mobil (UI + motor decizional) bazat pe *CRM Forever Platform Spec v1.1 FINAL* și *Model decizional v10.51*.

## Rulare
Deschide `index.html` în browser. Fișierul este autonom (funcționează și offline, exceptând fontul de iconuri).

## Publicare cu GitHub Pages
1. Încarcă `index.html` și `README.md` în repository.
2. Settings → Pages → Source: `Deploy from a branch` → branch `main`, folder `/ (root)`.
3. Prototipul va fi disponibil la `https://<utilizator>.github.io/<repository>/`.
